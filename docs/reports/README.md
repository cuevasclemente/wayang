# Historical review reports

These sanitized reports preserve design and review history for the Finance/MCP experiments. They are narrative records, not current release guarantees, executable setup instructions, or evidence that removed/internal artifacts are present in the public tree.

Private paths, personal identifiers, credentials, provider data, and the obsolete private SHA-256 manifest are intentionally excluded. Commands explicitly marked as normal-host or human-only must not be run by an agent. Current behavior and supported configuration are defined by `README.md`, `SECURITY.md`, and `docs/configuration.md`.

Report exploitable security issues through the private process in `SECURITY.md`, not by extending these public historical reports.
